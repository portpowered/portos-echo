# Architecture decision records

Create a numbered Markdown ADR in this directory before adding a package to Cargo.lock.
Name every added direct and transitive package it covers and cite the ADR in the PR.
Use this template, replacing its instructional text:

## Title

The decision title.

## Status

Proposed, accepted, or superseded.

## Context

The problem and constraints.

## Decision

The choice, rationale, and consequences.

## Packages covered

List the exact Cargo.lock package names covered by this decision.

Every ADR starts with author, owner, last modified, and status frontmatter.
